Canvas Lab（画布实验室）本地运行说明

一、启动

1. 将项目完整解压到一个可写目录，例如 D:\Infinite-Canvas\。
2. Windows 双击“启动服务.bat”；如果项目没有便携 Python，先运行“安装依赖.bat”。
3. 浏览器打开 http://127.0.0.1:3000/ 。启动窗口保持打开，关闭窗口会停止本地服务。
4. macOS 或 Linux 可在项目目录执行：

   python3 -m pip install -r requirements.txt
   python3 main.py

二、第一次使用

1. 左侧打开“API 设置”，点击“新增 API”。
2. 填写自己的平台名称、请求地址、协议和 API Key；也可以选择本机 ComfyUI 或已安装的 CLI 适配器。
3. 点击“验证地址”，再点击“拉取模型”，勾选要在画布中使用的模型并保存。
4. 返回“画布实验室”，新建画布后添加文本、图片、视频、音频或 3D 导演台节点。
5. 节点可以拖动、连线、添加参考素材和分段提示词；点击运行后，结果会回写到节点并保存到本地资产库。

三、可选连接方式

- OpenAI 兼容接口：填写完整的 Base URL 和 API Key。
- 异步接口：选择对应协议并按服务商要求填写任务路径。
- ModelScope：填写自己的访问令牌和模型 ID，LoRA 由用户在设置页手动添加。
- ComfyUI：启动本机 ComfyUI，填写地址（默认 http://127.0.0.1:8188），然后导入自己的工作流。
- CLI 适配器：先在本机完成对应 CLI 登录，再在 API 设置中选择适配器。

四、素材与数据

- 生成结果、画布和 API 配置默认保存在本机运行目录。
- 用户素材不会自动上传到项目维护者或第三方；是否发送到上游模型由你选择的 API/ComfyUI 决定。
- 不要把 API Key 写入网页、脚本或 Git 提交；推荐复制 `.env.example` 为 `.env` 后填写本地变量。

五、常见问题

- 端口被占用：停止旧的 Python 服务，或修改启动参数后重新运行。
- 页面空白：确认命令行没有报错，并使用 Ctrl+F5 刷新；检查浏览器控制台中的首个错误。
- 模型列表为空：检查 Base URL、协议、Key 和网络连通性；非 OpenAI 兼容服务请按其接口填写自定义路径。
- ComfyUI 任务卡住：确认 ComfyUI 地址可访问、工作流节点输入完整，并查看命令行日志。

Canvas Lab 是本地优先的开源工具，所有服务连接均由使用者自行配置和管理。
